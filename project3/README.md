# 🔐 Random Password Generator

## Project Overview

This project is a Random Password Generator developed using Python. It generates strong and secure passwords based on the length entered by the user. The password contains uppercase letters, lowercase letters, numbers, and special characters to improve security.

---

## Features

- User-defined password length
- Generates strong and secure passwords
- Uses Python's built-in `random` module
- Uses Python's `string` module
- Includes uppercase letters, lowercase letters, numbers, and special characters
- Beginner-friendly project

---

## Technologies Used

- Python 3
- random module
- string module
