# 📝 To-Do List Application

## 📌 Description
This is a simple Python-based To-Do List application developed as part of the DecodeLabs Python Internship Project 1.

The application allows users to:
- Add new tasks
- View all saved tasks
- Exit the application

This project demonstrates the use of Python lists, loops, conditional statements, and user input.

## 🚀 Features
- Add tasks to a list
- View all tasks with numbering
- Menu-driven interface
- Simple and easy to use

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python to-do-list.py
```
